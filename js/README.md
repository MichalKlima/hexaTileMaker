# JS module structure

This folder holds the main JavaScript application logic for the map editor.

## Planned modules

- `app.js` – global app bootstrap and object namespace
- `map.js` – map and hex grid logic
- `renderer.js` – SVG rendering
- `tools.js` – editor tools
- `storage.js` – save/load JSON project files
- `print.js` – print/export configuration

The current version keeps the initial structure lightweight and object-oriented.
